# Xiaobuding

A Windows local coding companion for a Chinese-speaking novice. Users choose an existing project, describe one outcome, and select frontend, backend or both. The confirmed division is native DeepSeek Harness for frontend and Codex ChatGPT login for backend, planning and fresh-session independent review. Frontend/backend tool choices are customizable, with native model and reasoning effort controls for each assignment. Review remains on Codex.

The user chose preassigned work with changes to subsequent dispatches during execution, and explicitly requested both model and reasoning-effort controls. Writers execute sequentially in one worktree, sharing task facts and evidence under one three-round budget. Never claim zero hallucinations or synchronization of private model conversations. Prefer automatic check discovery, native folder selection and a fresh full-stack example.

The user also wants native-agent-style execution visibility and faster startup for project investigation. An explicit read-only mode can use a plain directory or an existing Git worktree directly; modification tasks retain their controlled copy and acceptance flow. Surface actual tools, output and public messages without inventing private reasoning, progress percentages or old history.

Continuous project follow-up is essential: users must be able to ask more questions, supplement an unfinished batch, and begin another batch in the same project after inspection or acceptance. Keep task-scoped conversation and carry verified-source context to future native calls. Three rounds limit one batch's automatic implementation/rework loop, not the lifetime of a project. Questions do not consume those rounds. A new requirement cannot inherit a passing review of an older goal.

Model/effort choices must remain available for future questions after an inspection completes. Keep future preferences separate from sealed execution history, and apply them at the next dispatch. Agent controls belong in a toggleable side panel with role tabs, reachable while reading the project conversation without scrolling to the bottom.
